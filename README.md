# Vibe Coding 开发指南

Vibe Coding 开发笔记：环境、代码、调试和交付时随手查的 108 篇中文笔记。

遇到问题时可以按目录查，也可以挑一条阅读路线从头看。组件页能直接操作，需求模板把填写的内容整理成一段可复制的文字。首页会接着上次停留的地方，章节页保留当前方向的导航、页内目录和本机阅读记录。

主要入口为 `/`（首页）、`/learn`（目录）、`/courses/<模块>`（方向）、`/paths`（路线）、`/growth/prompt-templates`（需求模板）和 `/lab`（组件）；原有 108 篇章节地址继续有效。当前设计按 1280 / 1440 / 1600 px 桌面宽度验收，暂未进行手机端专项验证。

## 内容规划

已覆盖 9 个模块、108 篇章节正文，每个模块内的章节按「基础 / 进阶 / 精通」三级排列（起步模块只有基础）：

1. 起步：开发环境、编辑器与 AI 工具、代码规范、项目结构
2. AI 与 Agent：AI 基础、Agent 基础（Agent 循环、工具调用、MCP、规则文件、权限）、进阶（任务拆解、上下文管理、多 Agent、Hooks、评测）、精通（复杂协作、成本、团队规范、自建工具链、风险与合规）
3. Git 与协作：基础操作、PR 协作；进阶的改写历史与分支模型；精通的内部原理与大仓库
4. 前端与客户端：Web、iOS、Android、鸿蒙、小程序；进阶的状态管理、无障碍与国际化；精通的前端架构与渲染原理
5. UI 控件与提示词：17 个常用控件与动效（基础输入、反馈与浮层、导航与切换、列表与手势、微交互），每个控件附可操作演示、网页与手机 12 种写法、方案对比、常见坑，以及标注还原验证状态的提示词
6. 大前端 / 跨端：方案对比与各框架；进阶的原生桥接、构建发布；精通的运行时原理与长期维护
7. 后端与数据：框架、API、数据库、中间件、架构；进阶的事务并发与权限模型；精通的分布式与高可用
8. 质量与交付：测试、调试、审查、DevOps、安全；进阶的性能优化与可观测性；精通的故障处理与发布策略
9. 提升：提示词实践、读代码、实战案例；进阶的技术方案与重构；精通的模块负责与技术决策

前置知识按需交代，检查方法紧跟示例，常见错误在对应位置提醒。章节按主题组织，不要求统一的结尾问答。

## 维护约定

- 模块与章节的唯一数据源是 `docs/.vitepress/theme/data/modules.ts`：目录、命令面板、首页方向列表和当前方向翻页都由它生成。章节的 `level` 字段取「基础 / 进阶 / 精通」。
- 新增章节：先在 `modules.ts` 登记，再在对应目录新建 Markdown。正文没写完时在 frontmatter 加 `status: draft`，页面会显示「编写中」状态条和计划覆盖要点。
- 不编造案例、数据和评价；不确定的内容标注「待核实」。

正文覆盖不代表所有平台示例均已验证。原生片段尚未完成编译与真机验证，待校对项保留原标记；欢迎通过 Issue 和 PR 补充验证与实践经验。
