## 三问

回答得出这三个问题，再把这个方向的任务交给 AI。以下为计划展开的要点。

### 必须先懂什么

- 数据来源与口径
- API 调用的计费方式与限额

### 怎么验证

- 用小样本核对分析结果
- 为 API 调用设置超时与错误处理

### AI 常错在哪

- 编造数据或统计结论
- 把 API Key 写进前端代码
