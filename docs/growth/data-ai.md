## 计划覆盖

- 可选方向一：数据分析入门（SQL、Python 数据处理、可视化）
- 可选方向二：调用大模型 API（鉴权、请求、流式输出、费用控制）
- 数据隐私与合规的基本意识

## 三问

答得上这三个问题，再把这个方向的任务交给 AI。下面是计划展开的要点。

### 必须先懂什么

- 数据来源与口径
- API 调用的计费方式与限额

### 怎么验证

- 用小样本核对分析结果
- 为 API 调用设置超时与错误处理

### AI 常错在哪

- 编造数据或统计结论
- 把 API Key 写进前端代码
