## 三问

回答得出这三个问题，再把这个方向的任务交给 AI。以下为计划展开的要点。

### 必须先懂什么

- 请求从进入到返回经过哪些层
- 依赖注入与中间件的概念

### 怎么验证

- 用 curl 或接口工具实际请求接口
- 查看服务日志确认请求路径

### AI 常错在哪

- 混用框架不同大版本的写法
- 使用不存在的注解或配置项
