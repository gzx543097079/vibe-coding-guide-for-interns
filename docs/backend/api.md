## 三问

回答得出这三个问题，再把这个方向的任务交给 AI。以下为计划展开的要点。

### 必须先懂什么

- 状态码的语义
- 鉴权与授权的区别

### 怎么验证

- 覆盖成功、参数错误、无权限三类情况的接口测试
- 对照接口文档检查字段

### AI 常错在哪

- 状态码使用随意，错误都返回 200
- 忽略参数校验与权限校验
