## 计划覆盖

- MCP 要解决的问题：统一工具与数据源的接入方式
- 基本概念：客户端、服务器、工具、资源与提示词（以官方规范为准，待核实）
- 本地服务与远程服务的差异
- 安装第三方 MCP 服务前要看什么：来源、权限、数据流向

## 三问

答得上这三个问题，再把这个方向的任务交给 AI。下面是计划展开的要点。

### 必须先懂什么

- 接入一个 MCP 服务，就是把它的能力交给模型

### 怎么验证

- 读服务的文档或源码，确认它能访问什么

### AI 常错在哪

- 安装来路不明的服务，或给了过大的权限
