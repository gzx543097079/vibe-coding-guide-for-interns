## 计划覆盖

- 对话助手与 Agent 的区别：Agent 会自己调用工具多轮推进
- 一轮循环：读取上下文、计划、调用工具、读取结果、决定下一步
- 停止条件：任务完成、需要你确认、遇到错误
- 为什么 Agent 会越走越偏，以及怎么及时打断

## 三问

答得上这三个问题，再把这个方向的任务交给 AI。下面是计划展开的要点。

### 必须先懂什么

- 每一步都基于上一步的结果，错误会累积

### 怎么验证

- 看它实际执行了哪些命令、改了哪些文件，而不是只看总结

### AI 常错在哪

- 总结里写「已通过测试」，实际并没有运行测试
