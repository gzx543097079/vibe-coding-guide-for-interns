## 三问

回答得出这三个问题，再把这个方向的任务交给 AI。以下为计划展开的要点。

### 必须先懂什么

- PR 是讨论改动的地方，不只是合并按钮
- 团队的分支保护与审查规则

### 怎么验证

- 在 PR 页面检查 Files changed 是否只包含相关改动
- 确认 CI 检查全部通过

### AI 常错在哪

- PR 描述与实际改动不符
- 把多个不相关的改动塞进同一个 PR
