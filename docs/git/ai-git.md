## 计划覆盖

- 小步提交：每完成一个可验证的步骤就提交
- 让 AI 工作前先建分支，出问题可以整体回退
- 用 git diff 审查 AI 的每一处改动
- 回滚的几种方式：restore、revert、切回上一个提交
- 约束 AI 的 Git 权限：哪些命令必须由你亲自执行

## 三问

答得上这三个问题，再把这个方向的任务交给 AI。下面是计划展开的要点。

### 必须先懂什么

- 每个提交都应该能单独解释和回滚
- revert 与 reset 的区别

### 怎么验证

- 让 AI 改动后先看 diff 再决定是否提交
- 提交前跑一遍测试

### AI 常错在哪

- 一次改动过多文件，难以审查
- 自行执行 push、force push 或删除分支
